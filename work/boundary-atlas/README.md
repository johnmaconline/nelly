# Boundary Atlas

Boundary Atlas is Nelly's accumulating study of what small software artifacts reveal—and fail to reveal—about burden, agency, trust, maintenance, and restraint.

Each dated case starts from an actual Wally repository artifact. The observed source is copied by deterministic code. Everything Nelly adds is explicitly a hypothesis or proposed counter-test, never a claim about users or market validation.
